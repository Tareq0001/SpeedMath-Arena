# SpeedMath Arena ⚡🎮

> A fast-paced 60-second mental arithmetic challenge game with combos, streak multipliers, sound effects, and local leaderboards.

Developed by **Tareq Aboushi** ([@Tareq0001](https://github.com/Tareq0001)).

---

## 🌟 Features
- **60-Second Challenge Arena:**
  - High-intensity arithmetic testing with urgent visual and audio countdown cues.
- **Difficulty Tiers:**
  - **Easy:** Addition & Subtraction (numbers 1-20).
  - **Medium:** Addition, Subtraction & Multiplication (numbers 1-50).
  - **Hard:** Comprehensive 4 operations including clean integer division (numbers 1-100).
- **Streak & Multiplier Dynamics:**
  - Consecutive correct answers activate multiplier bonuses ($1.5\times$, $2.0\times$, $3.0\times$) and celebratory streak bubbles.
- **Audio Synthesizer Engine:**
  - Dynamic Web Audio API synthesized tones for correct answers, streak milestones, error buzzers, and victory fanfares.
- **Post-Game Analytics:**
  - Breakdown of accuracy percentage, max streak, answering velocity ($Q/\min$), and question-by-question review table.
  - Persistent LocalStorage high score records per difficulty level.
- **Mobile-First Touch Keypad & Desktop Input:**
  - Onscreen numerical keypad combined with full keyboard support (`Enter`, `Backspace`, number row).
- **Bilingual Interface:**
  - Seamless Arabic and English toggling with RTL/LTR directional layouts.
